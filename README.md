# VisionMate

Харааны бэрхшээлтэй хүмүүст орчноо **Монгол хэлээр, дуугаар** ойлгоход туслах
систем. Камер, зай мэдрэгч, AI-ийн тусламжтай ажиллана. PineQuest S5 · Episode 1 · Team 4.

> VisionMate нь таяг, хөтөч нохой болон бусад хөдөлгөөний туслах хэрэгслийг
> **орлохгүй**. Систем "зам чөлөөтэй", "аюулгүй" гэж хэзээ ч хэлэхгүй.

## Боломжууд

| Горим | Юу хийх |
| --- | --- |
| Орчноо таних | Нэг зураг авч орчныг 1–4 өгүүлбэрээр тайлбарлана |
| Энийг унш | Бичиг, шошго, эмийн хайрцгийг Монголоор уншина |
| Алхах горим | Хүн, машин, хаалга, шатыг зайтай нь шууд сэрэмжлүүлнэ |
| Зай | Камер чиглэсэн зүйл хүртэлх зайг метрээр хэлнэ |

Монгол дууг [Чимэгэ](https://chimege.com) TTS-ээр гаргана — ихэнх төхөөрөмжид
Монгол хоолой суугаагүй байдаг.
