# VisionMate

Харааны бэрхшээлтэй хүмүүст орчноо **Монгол хэлээр, дуугаар** ойлгоход туслах
систем. ESP32-CAM камер ба AI-ийн тусламжтай ажиллана. PineQuest S5 · Episode 1 · Team 4.

> VisionMate нь таяг, хөтөч нохой болон бусад хөдөлгөөний туслах хэрэгслийг
> **орлохгүй**. Систем "зам чөлөөтэй", "аюулгүй" гэж хэзээ ч хэлэхгүй.

## Боломжууд

| Горим | Юу хийх |
| --- | --- |
| Орчноо таних | Нэг зураг авч орчныг 1–4 өгүүлбэрээр тайлбарлана |
| Энийг унш | Бичиг, шошго, эмийн хайрцгийг Монголоор уншина |
| Алхах горим | Хүн, машин, хаалга, шатыг шууд сэрэмжлүүлнэ |

Монгол дууг [Чимэгэ](https://chimege.com) TTS-ээр гаргана — ихэнх төхөөрөмжид
Монгол хоолой суугаагүй байдаг.

## Ажиллуулах

Node.js 22+ шаардлагатай.

```bash
cd backend
npm install
npm run dev     # http://localhost:8000/health
npm test
```

Апп (Expo dev build — native хэсэгтэй тул Expo Go-д ажиллахгүй):

```bash
cd mobile
npm install
npx expo run:ios   # эсвэл run:android
```

## Хөгжүүлэлтийн журам

- Функц бүрийг тусдаа салбар, **≤160 мөрийн** PR-ээр оруулна.
- PR бүрийн дараа апп ажиллаж, тест давсан байх ёстой.
- API түлхүүрийг зөвхөн `backend/.env`-д хадгална — хэзээ ч commit хийхгүй.
- PR бүрт GitHub Actions автоматаар backend-ийн typecheck, тест, mobile-ийн typecheck, lint-ийг ажиллуулна.
